# 学习任务板 · 固定 Demo 样例

这是 Dream Maker 的无云端依赖演示夹具；不能用来证明 Codex/DSH 已经根据任意灵感完成创作。

运行：在本目录使用 `python -m http.server 8080 --bind 127.0.0.1`，再打开 `http://127.0.0.1:8080`。不要通过 file:// 打开 ES 模块。

支持添加、完成、删除与筛选。独立打开时使用当前浏览器存储；在原 Dream Maker 的来源核对预览中，v2 数据消息使用本机项目数据和明确版本，不获得主应用、文件或模型接口。旧成果仍使用原浏览器副本，需在原应用明确迁移；旧源码不被覆盖。

保存结果不明或版本冲突时保留页面内容、停止自动写入，可查看和复制当前任务 JSON，再明确选择读取已保存版本；不自动合并或重试。本机任务历史可通过原应用的状态备份/演练单独恢复为新版本。这个固定样例不是通用 Live 数据适配、完整项目恢复或四角色成功证明。无云端账户和同步。
